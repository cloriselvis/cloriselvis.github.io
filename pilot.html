Pilot scope

Good fit

Event lists, form exports, old CRM exports, recruiter lists, and small agency lead sheets under 2,000 rows.

Not included

No scraping, enrichment, email verification, bulk sending, compliance advice, or guaranteed deliverability claims.

Privacy rule

Do not post private contact data in GitHub issues. Start with a sanitized sample or describe the file.

Why this exists

Fixing a bad phone column in a CSV takes minutes; merging hundreds of duplicates inside a CRM can burn an afternoon. The pilot focuses on catching those problems pre-import.

How to request a review (no private data)

1) Open the app

Paste or upload your CSV locally. Nothing is uploaded to a server.

2) Clean + copy summary

Click Clean list, then click Copy summary. The summary contains only metrics, column headers, and issue counts (no raw rows).

3) Paste into the pilot request

Paste the summary into the GitHub pilot request issue so the review can start without sensitive data.
